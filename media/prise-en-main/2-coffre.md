# 🧠 Créer ton second cerveau

Forge range tout dans un **coffre Obsidian** : un dossier de notes Markdown.

- `Prosits/` : un CER par note
- `Notions/` : une note par notion, reliée aux Prosits qui en parlent
- `Exercices/` : tes exercices de code et tes études de cas

Ouvre ensuite ce dossier dans **Obsidian** (« Ouvrir un dossier comme coffre ») et regarde la **vue graphe** (Ctrl+G).
